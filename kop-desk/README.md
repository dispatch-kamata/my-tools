# KOP DESK

リヴァプールFC 2026/27 を追いかける、個人用ダッシュボード。
試合・スカッド・フォーメーション・監督/戦術・移籍を1画面にまとめています。

日程・スコア・試合スタッツ・負傷者は **FotMobから自動で取得**します。
スマホ（iPhone Safari）で見ることを前提に作ってあります。

---

## ファイルの中身

| ファイル | 役割 | 触るか |
|---|---|---|
| `index.html` | アプリ本体（見た目と動き） | ほぼ触らない |
| `data.js` | **中身のデータ全部**（寸評・移籍・戦術…） | ここだけ書き換える |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 | 触らない |
| `icon-180.png` / `icon-512.png` | ホーム画面アイコン | 触らない |

---

## データの仕組み（2段構え）

```
起動
 ├─ ① data.js を読む     ← 必ず表示される土台。オフラインでもここまでは出る
 └─ ② FotMob に取りに行く ← つながれば日程・スコア・スタッツ・負傷者を上書き
      失敗したら①のまま（画面は壊れない）
```

画面右上のバッジが今どちらかを示します。

- 緑の **`FotMob 03:45`** … 最新データを取得済み（時刻は取得した時間）
- グレーの **`保存データ`** … 取得できなかったので data.js の内容を表示中

**バッジをタップすると、その場で取り直します。**

### FotMobから自動で入るもの

- プレシーズン／プレミアリーグの日程（キックオフ時刻は日本時間に自動換算）
- 試合結果とスコア、得点者と時間
- 試合スタッツ（支配率・シュート・パス・守備・デュエル）→ 棒グラフ
- 実際のスタメンとフォーメーション、**選手ごとの採点**、マン・オブ・ザ・マッチ
- 負傷者リストと復帰見込み
- 背番号・年齢・身長・市場価値

### data.js に手で書くもの

- 選手の日本語名と寸評
- 移籍の解説文、監督の戦術メモ
- 予想スタメン（`formation`）
- 試合のコメント（`notes`）とハイライト動画のリンク
- クラブの日本語名とエンブレム番号

つまり **「数字はFotMob、言葉は data.js」** です。

## GitHub に置いて iPhone から見る（初回だけ）

git のコマンドは使いません。全部ブラウザの画面操作でできます。

### 1. リポジトリを作る

1. GitHub にログイン → 右上の **＋** → **New repository**
2. **Repository name** に `kop-desk` と入力
3. **Public** を選ぶ（※ GitHub Pages を無料で使うため）
4. **Create repository** を押す

### 2. ファイルを上げる

1. **Add file** → **Upload files**
2. `kop-desk` フォルダの中の**5つのファイルを全部**ドラッグ＆ドロップ
3. 下の **Commit changes** を押す

### 3. サイトとして公開する（GitHub Pages）

1. **Settings** → 左メニューの **Pages**
2. **Source** を `Deploy from a branch`
3. **Branch** を `main` ／ フォルダは `/ (root)` にして **Save**
4. 1〜2分待って再読み込みすると、上の方にアドレスが出る

```
https://miyarn69.github.io/kop-desk/
```

### 4. iPhone のホーム画面に置く

1. iPhone の **Safari** で上のアドレスを開く
2. 画面下の**共有ボタン**（□に↑のマーク）をタップ
3. **「ホーム画面に追加」** を選ぶ
4. アイコンから起動すると、Safariのバーが消えて**アプリと同じ見た目**になる

## data.js を書き換える

1. GitHub で **`data.js`** をクリック
2. 右上の**鉛筆マーク**（Edit this file）を押す
3. 書き換える
4. 下の **Commit changes** を押す
5. **1〜2分**でサイトに反映（iPhone側は再読み込み）

### コツ

- **記号（ `,` `"` `{` `}` ）は消さない。** 中の文字だけ書き換える。
- 迷ったら、すでにある行を**まるごとコピーして下に貼り、中身だけ変える**のが安全。
- 画面が真っ白になったら記号がどこか欠けている。
  GitHub の **History** から1つ前に戻せば必ず直る。
  （アプリ側も、読めなかったときは日本語で案内を出すようにしてある）

## よくある書き換え

### 試合のコメントを書く

`results` の中の `notes` を書き換える。`<b>ここ</b>` で太字になる。

```js
notes: [
  "<b>イラオラ体制の初陣を勝利で飾る。</b>後半に3点を奪って逆転。",
  "Joe Gomez が10分で負傷交代。"
],
```

試合が新しくなると FotMob 側のデータで結果カードが差し替わるので、
新しい試合のコメントを書きたいときは `fmMatchId` を新しい試合のものに合わせて
`notes` と `video` を書き換える。

### 選手の寸評を直す

`squad` の中の該当行の `note` を書き換えるだけ。

```js
{ id:"florian-wirtz", ..., note:"背番号7。トップ下の主役。" },
```

年齢・身長・背番号・負傷はFotMobが上書きするので、触らなくてよい。

### 予想スタメンを変える

`formation` の `xi` を書き換える。
`id` は `squad` の `id` と同じ文字列にすること。
`x` は左右（0=左端、100=右端）、`y` は縦（0=自陣ゴール、100=相手ゴール）。

### 新しいクラブのロゴを出す

`clubs` に1行足すだけ。`code` はプレミアリーグ公式のエンブレム番号。

```js
everton: { ja:"エヴァートン", en:"Everton", short:"EVE", code:"t11", color:"#003399" },
```

番号が分からないクラブ（海外クラブなど）は `code:null` にすると、
自動で `short` の頭文字マーク（例：`MON`）で表示される。

## 技術メモ

- 外部ライブラリなし。`index.html` と `data.js` だけで動く。ローカルでもそのまま動く。
- エンブレムはプレミアリーグ公式CDNの200px PNG。
  読み込めないクラブは自動で頭文字マークに落ちるので、画面が壊れることはない。
  （SVG版は一部クラブが単色の簡略ロゴなので、あえてPNGに統一している）
- `data.js` は毎回 `?v=時刻` を付けて読み込む。
  こうしないと、GitHubで更新しても iPhone が古いデータをキャッシュし続ける。
- FotMob は `Access-Control-Allow-Origin: *` を返すので、
  サーバーもAPIキーもなしにブラウザから直接読める。
  ただし**公式に公開されたAPIではない**ため、仕様変更で止まる可能性がある。
  そのときも `保存データ` にフォールバックするだけで、アプリは動き続ける。

## この先

FotMobの自動更新が止まったとき、あるいは履歴を貯めたくなったときは、
配車システムと同じ **Xserver + MySQL + cron** の構成に移せる。
アプリ側は「データを読んで表示するだけ」なので、
`data.js` を PHP が吐き出す形に差し替えれば画面はそのまま使える。
